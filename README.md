# EffiSim – Efficient Portfolio Simulator

An interactive Streamlit app inspired by Modern Portfolio Theory and CAPM. It allows users to simulate and visualize thousands of portfolio combinations, analyze their risk/return profiles, and identify optimal allocations.

## Features
- Efficient frontier simulation
- Risk-return visualization
- Sharpe and Treynor ratio analysis
- Risk-free rate integration from FRED
